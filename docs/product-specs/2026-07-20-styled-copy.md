# Styled Copy

Status: implemented contract
Last updated: 2026-07-20

## Goal

Styled Copy converts a frozen editor document or selection into sanitized,
publication-specific rich HTML and plain text for pasting into WeChat Official
Accounts or Zhihu. It is a clipboard workflow, not a remote publishing channel:
Novelist does not authenticate to either target or submit content on the user's
behalf.

## Entry Point And Source Ownership

The editor share menu opens one dialog with Online Publish and Styled Copy
modes. Styled Copy remains available when no online channels are configured.

Opening the dialog freezes the active pane's source identity and selection.
Ordinary editors use the current CodeMirror state. Large-file editors use one
generation-tagged Rope snapshot. A stale source, unavailable snapshot, project
switch, pane replacement, or superseded operation stops conversion instead of
copying a different document.

The available scopes are `selection`, when the frozen source contains a
nonempty main selection, and `full-document`. Full document is forced when no
selection exists. Front matter is removed from the converted source. Styled
Copy never modifies the editor buffer, file contents, online Publish form, or
remote identity.

## Targets And Presentation

| Target | Themes | Default links |
|---|---|---|
| WeChat | Minimal, Magazine, Technical | End references |
| Zhihu | Fixed Zhihu presentation | Inline anchors |

The user may override either target's link mode with inline anchors or end
references. Theme and target changes rebuild the preview from the frozen
semantic source. Preview runs in a sandboxed `srcdoc` iframe with no referrer.

## Conversion Pipeline

1. Resolve selected or full Markdown from the frozen source.
2. Convert through the bounded Styled Copy Pandoc profile.
3. Parse and normalize the result into Novelist's semantic document model.
4. Enforce document, nesting, table, attribute, and URL limits.
5. Resolve images and Mermaid blocks for preview.
6. Render the selected target and theme.
7. Sanitize against the final tag, attribute, style, and URL allowlists.
8. On Copy, resolve final hosted assets, render and sanitize again, validate the
   final HTML/plain-text pair, and write both clipboard representations in one
   native command.

The preview is never treated as the final clipboard payload. Copy is disabled
until a current preview exists, deduplicated while in flight, and reports
success only after the native clipboard write succeeds.

## Assets

Existing absolute HTTPS images remain remote. Local PNG, JPEG, GIF, and WebP
references are read through the native Styled Copy capability boundary.
Absolute local paths are accepted only when their canonical target remains
inside the retained document/project roots; paths outside those roots are
rejected. Symlink escapes, unsupported formats, malformed encodings, empty
bytes, unsafe schemes, and invalid hosted URLs fail closed.

Mermaid sources are rasterized to PNG under strict source, SVG, and dimension
limits. Preview uses data URLs and performs no upload. Final Copy requires an
active image host for every local or generated byte asset. Assets are grouped
by SHA-256, uploaded with bounded concurrency, and successful uploads are reused
within the controller session. The final payload accepts only credential-free
absolute HTTPS asset URLs.

If any asset cannot be resolved or uploaded, Copy remains unavailable and every
failed asset is listed. A partial asset set is never copied.

## Safety And Degradation

Active raw HTML and unsafe Pandoc extensions are disabled. The semantic
normalizer rejects malformed roots, disallowed tags or attributes, unsafe
styles, invalid links and images, structurally empty table rows, and documents
above the configured complexity limits.

Recoverable differences produce bounded warnings, including removed unsafe or
relative links, malformed footnotes or images, table degradation, and degraded
math presentation. Blocking failures expose localized reason categories and do
not include credentials, raw provider diagnostics, arbitrary file paths, or
unbounded Pandoc output.

Destroying the dialog aborts the active generation. Late conversion, asset,
upload, or clipboard results from an older generation cannot replace current
state or report false success.

## Acceptance Criteria

- Styled Copy works without an online Publish channel.
- Selection and full-document scope use the frozen active pane and never cross
  into another pane or project.
- WeChat and Zhihu render their documented defaults and link overrides.
- Preview performs no image-host upload.
- Final Copy uploads each distinct local/generated asset at most once per
  attempt and retries only failed work.
- Missing Pandoc support, stale sources, unsafe HTML/URLs, asset failures, and
  clipboard failures block success with bounded feedback.
- The final native clipboard contains both sanitized HTML and plain text.
- Closing or switching modes cannot leak late results or mutate Online Publish
  state.
