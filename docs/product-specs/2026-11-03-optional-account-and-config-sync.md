# 可选账号与跨设备配置同步

状态：独立可选后端与 App 接入已实现并完成本机联调；尚未完成全部发行平台验收，未部署。
更新日期：2026-11-03

## 目标

Novelist 保持本地优先。用户在新设备上安装后，不登录也能直接开始写作；愿意登录的用户，可以恢复个人配置与 WebDAV 连接信息，再选择需要下载和同步的项目。

**无需账号即可完整使用，是长期产品要求。** 未登录模式是正常使用方式，不是试用、临时会话或功能受限的游客模式。

本文定义本轮需求与数据边界。源码实现及本机调试包不等于已发布账号服务，也不改变现有候选包的发布状态。

## 已确认的产品原则

1. 新设备无需注册、登录、联网或绑定 WebDAV，即可创建、打开、编辑、保存和导出本地项目。
2. 账号用于提供可选的跨设备便利，不作为本地写作或手动 WebDAV 同步的使用资格。
3. 用户可以一直不登录，也可以先使用本地功能，之后再登录；登录时保留已有项目和配置。
4. Novelist 账号、WebDAV 服务账号、项目同步分别管理，界面与文案清楚区分。
5. 登录不会自动上传所有项目、启用所有同步或覆盖本地配置。
6. 账号服务故障、登录过期或配置同步失败，不得阻断本地保存与继续写作。
7. 退出登录和删除 Novelist 账号，不得自动删除本地稿件或 WebDAV 上的项目。

## 账号、配置与项目的关系

| 层级 | 职责 | 与登录的关系 |
|---|---|---|
| 本地工作区 | 本机项目、正文、附件及设备状态 | 无需登录，数据先保存在本地 |
| Novelist 账号 | 身份、设备管理、可选的配置同步 | 用户自愿登录后使用 |
| 用户配置 | 编辑偏好、主题、快捷键、AI 配置、WebDAV 连接资料 | 经用户选择后跨设备同步 |
| WebDAV 服务账号 | 用户选择的存储服务地址与访问凭据 | 可在未登录时手动配置；与 Novelist 账号独立 |
| 项目同步 | 每个项目的远端身份、正文、附件、同步基线和冲突 | 继续按项目独立启用，通过 WebDAV 同步 |

Novelist 账号服务承担身份和配置存储，不因增加账号而自动承担正文托管。远端项目继续以独立项目身份隔离；同名项目不能被当作同一份同步数据。

既有实现具有全局 WebDAV 连接资料、项目绑定和独立项目同步；账号层复用这些能力，不另造项目同步协议。既有架构见[移动端平台计划](../exec-plans/active/2026-10-28-mobile-platform.md)和[移动端部署说明](../design-docs/mobile-deployment.md)；其中早期“不提供 Novelist 账号服务”的说明记录的是当时的 WebDAV 架构，不代表独立可选后端的当前实现或生产部署状态。

账号与配置服务归属同级独立项目 `novelist-backend/`，是可选组件，不放入 App 的构建产物或启动依赖。App 通过版本化接口主动接入；未配置该服务时继续完整使用本地写作与手动 WebDAV。项目边界和加密同步设计见[可选后端设计](../../../novelist-backend/docs/optional-account-and-config-sync.md)。

## 核心用户流程

### 新设备直接使用

- 首次启动直接提供创建项目、打开/导入项目等入口，不以登录页面阻挡写作。
- 登录入口可见但不打断操作；不反复弹窗要求登录，不将正常写作流程标记为“未完成注册”。
- 用户离线完成写作、保存、重开、导入和导出，本地数据持续保留。
- 用户需要 WebDAV 时，可直接手动配置、测试连接、绑定项目，无需 Novelist 账号。
- WebDAV 新连接默认使用服务地址下独立的 `Novelist` 文件夹，也可选择自定义相对目录或明确直接使用地址所指的目录；项目正文与快照都遵循此选择。旧连接保留原目录，不自动搬移远端数据；修改已有项目的目录会先暂停同步，须由用户重新启用。

### 已有本地数据后登录

- 明确告知账号提供哪些同步能力，并由用户选择是否开启配置同步。
- 首次同步展示本地配置和云端配置的差异，让用户选择合并、使用本地或使用云端；操作前保留可恢复的本地配置副本。
- 登录不自动改变项目目录、不上传全部稿件、不重建现有项目身份。
- 已手动配置的 WebDAV 连接保留；只有用户选择纳入同步后，才加入账号的加密配置。

### 新设备登录并恢复

1. 用户可以直接写作，也可以主动选择登录。
2. 登录后选择恢复配置；含敏感信息时，完成独立的解密/恢复步骤。
3. 显示将恢复的设置分类和 WebDAV 连接名称，允许选择；秘密值默认隐藏。
4. 恢复 WebDAV 信息后重新测试连接，连接失败时提供修改或重新授权入口。
5. 用户主动查看远端项目、选择下载，再开始该项目的同步；不自动下载全部项目。

恢复连接资料不等于连接已有效，连接成功不等于项目已同步。界面分别显示账号登录、配置同步、WebDAV 连接和当前项目同步状态。

### 离线、退出与切换账号

- 已登录设备离线时继续使用本地配置并写作；配置变化在本地排队，恢复连接后处理同步。
- Novelist 登录过期不会使已保存的 WebDAV 凭据凭空失效；只要 WebDAV 凭据仍有效且项目已启用同步，就不额外要求 Novelist 登录。
- 退出时说明哪些账号凭据及本地解密材料会移除，并让用户决定是否保留已恢复的 WebDAV 连接。移除连接时暂停相关项目同步，保留稿件、项目身份和可恢复的同步记录。
- 保留的连接继续作为本机独立配置使用，不再参与原账号的配置同步。当前退出界面默认保留已恢复的连接；用户可明确选择移除，手动配置的独立连接不受影响。
- 账号 A 切换到 B 时，不能将 A 的配置或秘密自动上传给 B；本地项目仍保留，账号之间的配置归属须明确。
- 删除 Novelist 账号时清除服务端账号数据与加密配置，明确说明已下载的本地稿件和独立 WebDAV 项目不随之删除。

## 配置同步范围

| 分类 | 需求 |
|---|---|
| 通用偏好 | 编辑行为、主题偏好等可跨设备使用的设置，可选择同步 |
| 快捷键与布局偏好 | 按平台能力适配；保留源配置，不将桌面专用操作强加给手机 |
| AI 连接与预设 | 服务地址、模型参数、提示词等可选择同步；API Key 归入敏感信息 |
| WebDAV 连接资料 | 连接名称、地址、用户名及必要的绑定描述可恢复；密码、应用密码、令牌归入敏感信息 |
| 设备专属状态 | 绝对文件路径、窗口坐标、系统权限、键盘状态、硬件信息等留在设备上 |
| 项目内容与项目设置 | 继续随项目管理和同步，不并入用户配置包 |
| 同步运行状态 | 文件哈希、ETag、扫描记录、锁、设备上的同步基线不作为通用配置复制 |

项目到 WebDAV 连接的引用可以携带可迁移的标识，但不能把另一设备的本地路径或基线当作当前设备的有效绑定。下载既有项目时沿用该项目身份，再建立本机状态。

## 敏感信息与数据边界

- 普通配置同步与敏感凭据同步分别让用户选择；登录本身不视为同意上传密码或 API Key。
- WebDAV 密码、应用密码、令牌及 AI API Key 跨设备同步必须端到端加密；Novelist 服务端保存密文，不持有可直接解密这些秘密的密钥。
- 设备使用系统安全存储保护凭据和密钥；不得为实现跨设备同步而退回明文存储。
- 账号认证和配置解密分别设计。账号登录或账号密码重置，不应让服务端自动取得旧密文的解密能力。
- 无可用解密密钥、恢复材料或可信设备时，说明无法恢复的内容，允许重新填写凭据；不得阻止打开本地项目。
- 提供设备列表、会话撤销和同步范围管理。撤销设备能阻止后续账号访问，但不能承诺擦除离线设备已解密保存的数据；WebDAV 应用密码仍需在相应服务端撤销。
- 日志、诊断、错误提示和遥测不得包含秘密值、解密材料或完整授权头。
- 手动配置的 WebDAV 在不登录时仍可使用；所有模式保留 TLS 校验和现有冲突保护。

## 配置冲突、兼容与恢复

- 配置带 schema 版本和同步修订信息；不能仅靠设备时钟决定覆盖顺序。
- 不同字段的独立修改可以按明确规则合并；同一字段同时修改时保留双方版本，提供选择或恢复入口。
- 删除也属于同步变更。用户删除的连接或 AI profile 不得因旧设备上线或默认模板重新生成而复活。
- 配置应用与本地持久化采用原子写入；断网、进程终止或版本不兼容不应留下半套可用配置。
- 平台不支持的配置予以保留，并说明未生效的原因；不将这种差异反向同步成另一设备的删除操作。
- 恢复账号配置不自动开始项目上传、删除、重新绑定或迁移远端目录；这些操作保留项目级确认边界。

## 验收标准

| 场景 | 必须满足 |
|---|---|
| 全新安装且未登录 | 无登录前置，能创建/导入项目、输入中文、保存、重开、导出 |
| 全新安装且离线 | 本地功能可用，不因认证或账号服务请求失败卡住启动 |
| 未登录使用 WebDAV | 手动配置、连接测试、项目绑定及同步可完成 |
| 写作后再登录 | 本地稿件保留，配置不被静默覆盖，项目不被自动上传 |
| 第二台设备恢复 | 经选择和解密恢复设置与 WebDAV 信息；重新连接后可选择下载项目 |
| 拒绝同步敏感信息 | 普通配置仍可同步；新设备提示补填凭据，不误报连接成功 |
| 账号服务不可用/令牌过期 | 本地编辑保存不受阻；独立有效的 WebDAV 同步不受账号登录门禁限制 |
| 双端修改/删除配置 | 冲突可处理、版本可恢复；删除不会被旧设备或模板复活 |
| 退出或切换账号 | 不丢本地稿件，不将旧账号的秘密上传给新账号 |
| 丢失恢复材料 | 明确恢复边界，允许重新填写凭据，保留本地使用能力 |
| 删除账号或撤销设备 | 清楚说明作用范围，不误删本地/WebDAV 项目，不承诺远程擦除离线副本 |

验收覆盖桌面、Android、iPhone 和 iPad。浏览器测试用于界面与状态逻辑，原生安全存储、恢复、生命周期和跨设备同步需有实际运行证据。

## 阶段与待定事项

已确认采用独立自建、可选接入的后端方向，允许开发和本机联调；账号功能不作为当前 WebDAV/移动端真机测试的前置条件。实现进度与验收记录见[本轮迭代计划](../exec-plans/active/2026-11-03-optional-account-and-config-sync.md)。

部署前需与产品方商定具体服务器、构建发布方式、部署上线流程和域名。本轮不部署，不将开发选型或本机运行证据等同于生产上线决策。

当前已实现的技术边界：

- 用户名/密码登录、设备会话、会话撤销和需要密码确认的账号删除，由独立可选后端提供；生产托管与运维责任尚待商定。
- 独立的随机 256 位恢复密钥用于 AES-GCM 配置加密；会话令牌、恢复密钥和设备恢复日志密钥使用系统安全存储。登录不会解密旧配置，丢失恢复材料时不能由服务端恢复密文。
- 配置文档使用 schema 2，按分类和稳定字段标识同步，通过修订条件写入、三方合并和删除墓碑保留冲突与删除语义；恢复前写入加密恢复日志和用户可恢复副本。
- 首期提供通用偏好、快捷键、AI 连接/预设和当前共享 WebDAV 连接，秘密单独选择。首次预览、冲突选择、退出后保留连接和恢复失败交互见[设置架构](../design-docs/settings.md#novelist-account-and-webdav)。
- 多个 WebDAV 连接的模型扩展、全部发行平台的安全存储/真机验收，以及服务成本、隐私与支持政策仍需单独完成；既有项目绑定不在登录时自动迁移。

生产服务器、构建发布方式、上线流程、域名和发版时间尚未确定；本机实现与历史联调记录不等于生产服务已上线。
