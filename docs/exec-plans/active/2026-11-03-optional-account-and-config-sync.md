## 授权与范围

用户确认可继续开发。账号、设备会话和加密配置存储在同级独立 `novelist-backend/` 项目实现，App 只保留可选客户端接入。未登录、未配置后端和账号服务故障不影响本地写作或独立 WebDAV。

部署前必须商定具体服务器、构建发布方式、上线流程和域名；本轮仅本机运行、测试与联调，不修改生产环境。

## 实施顺序与完成条件

| 工作项 | 完成条件 |
|---|---|
| 独立后端 | 持久化账号、密码摘要、设备会话及配置密文；会话撤销、账号隔离、条件写入和删除账号实际运行通过 |
| 原生客户端 | 账号请求由原生层处理；令牌和恢复密钥使用系统安全存储；退出支持离线清理；服务和账号隔离 |
| 配置适配 | 选择通用偏好、快捷键、AI 配置、既有 WebDAV 连接；排除设备路径、项目配置和运行基线；秘密另行授权 |
| 加密与合并 | 独立恢复密钥、认证加密、首次差异预览、三方字段合并、墓碑、并发修订冲突和加密恢复副本 |
| 设置界面 | 可选登录、独立解密、同步范围、冲突选择、恢复、设备撤销、退出与删除边界；WebDAV 与账号状态分开 |
| 本机联调 | 启动真实后端，模拟两台设备恢复及并发修改；运行 App 界面并观察未登录路径；原生安全存储单独验证 |
| 平台验收 | 桌面、Android、iPhone、iPad 的真实结果分别记录；未运行的平台保持未验收状态 |

当前适配既有全局 WebDAV 连接，不改变项目同步协议或自动迁移项目绑定。恢复多个连接的模型扩展需保留稳定标识；不能借本次迭代自动下载、绑定或上传项目。

## 验证重点

- 全新未登录启动无账号网络请求；登录不应用配置、不上传项目、不隐式同意配置同步。
- 普通配置可单独恢复；未选择秘密时保留本机凭据，新设备需补填，不误报 WebDAV 已连通。
- 双端独立修改合并；同字段冲突保留双方；旧修订拒绝覆盖；删除不因旧设备或模板复活。
- 离线修改加密保留；恢复连接后重试；账号会话过期不影响本地写作和独立 WebDAV。
- 恢复前保留加密副本，跨设置与凭据库中断可恢复；恢复副本后暂停自动同步。
- 退出或切换账号清理账号材料，不自动上传旧账号秘密；删除账号和设备撤销不删除本地/WebDAV 项目。
- 日志与界面不得显示密码、API Key、令牌和解密材料；恢复密钥只在明确生成并要求保存时显示。
