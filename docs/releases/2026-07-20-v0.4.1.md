# v0.4.1 Release Notes

**Date:** 2026-07-20
**Tag:** `v0.4.1`
**Package version:** `0.4.1`

## Theme

v0.4.1 is a focused editor interaction patch. It repairs selection and
keyboard navigation on lines containing several inline formulas, and keeps the
Block Type submenu anchored correctly when application zoom is not 100%.

## Shipped

- Inline `$...$` math reveals editable source as soon as a cursor or
  Shift+Arrow selection reaches either delimiter.
- Selections spanning several formulas reveal every touched formula instead of
  mixing stale rendered widgets with editable source.
- Long wrapped math source no longer gets fragment padding that creates gaps or
  selection artifacts.
- Display-math source styling continues to refresh when a selection enters a
  `$$...$$` block.
- The Block Type submenu converts scaled DOM rectangles back to root layout
  coordinates before positioning, preserving trigger adjacency, viewport
  flipping, and vertical clamping at every application zoom level.
