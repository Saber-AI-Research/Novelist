# v0.4.0 Release Notes

**Date:** 2026-07-20
**Tag:** `v0.4.0`
**Package version:** `0.4.0`

## Theme

v0.4.0 combines a new publication-ready clipboard workflow with a broad
reliability pass across editing, project lifecycle, AI sessions, exporting, and
online publishing. The release makes remote updates explicit and duplicate-safe
while strengthening every transition that can move or retire unsaved state.

## Shipped

- Styled Copy converts a frozen selection or document into sanitized WeChat or
  Zhihu HTML and plain text, with target previews, themes, link modes, local
  image hosting, Mermaid rendering, and native clipboard output.
- Ghost, self-hosted WordPress, and WordPress.com support verified binding and
  update-in-place publishing. Conflict, missing-post, overwrite, rebind, and New
  Copy flows never silently create a duplicate. Medium remains explicitly
  create-only.
- Publishing forms and content-addressed cover assets persist per document and
  channel. Cover images support file selection and real macOS Command+V paste.
- File rename and move operations flush pending writers, journal the intended
  transition, migrate all owned sidecars and encoding state, retarget open
  editors, and retry idempotently after partial metadata failure.
- External reload delivery preserves IME composition and dirty buffers while
  notify and polling paths converge to one current state.
- Editor block transforms and structural Tab actions preserve CJK text,
  selections, markers, and one-step undo.
- AI Agent project/session ownership prevents stale output, retries, or apply
  actions from crossing project boundaries.
- Pandoc, updater, export CSS, project watcher startup, and release automation
  have stricter bounded failure and cleanup behavior.
