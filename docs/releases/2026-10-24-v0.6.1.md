# v0.6.1 Release Notes

**Date:** 2026-10-24
**Tag:** `v0.6.1`
**Package version:** `0.6.1`

## Theme

A hardening release that follows a full-codebase review. It fixes several paths
where unsaved writing could be lost: conflict "Keep mine", the same file open in
two split panes, typing during a save, Cmd+W on an empty split column, and Zen
mode saves. It also closes plugin sandbox escapes and makes WebDAV sync
propagate deletions. Book Translation projects ship as a new bundled feature.

## Shipped

- **Save integrity:** every save path goes through `tabsStore.saveTab(id)`, which
  writes the tab's own editor text and marks a tab clean only if its live text
  still matches what was written. Auto-save moved to `app/lib/services/autosave.ts`.
- **Editor:** unclosed `$$` / front matter no longer drop the rest of the syntax
  tree; image upload positions are mapped through later edits; formatting
  toggles keep the caret; KaTeX, scroll guard, slash menu, and table fixes.
- **Plugin security:** plugin iframes are sandboxed into opaque origins and talk to
  the host only over a per-document `MessagePort`; bundled plugins ship a strict
  hash-based CSP; plugin ids must equal their folder name; document content
  requires the `read` permission; QuickJS plugins run on their own threads with a
  2 s caller-side timeout. **Breaking for third-party UI plugins:** they must adopt
  the port handshake (`plugins/host-channel.ts`).
- **Sync and files:** WebDAV deletions and renames propagate in both directions
  using the last common version, with ETag-based download skipping and a
  legacy-namespace claim so devices cannot silently diverge. Watchers stop with
  their window, `delete_item` is confined to the project, and recent projects,
  plugin settings, AI files, and writing stats are written atomically.
- **Book Translation:** EPUB/TXT import into per-chapter `.novtrans` files with
  host-mediated Google/LLM reference translations.
- **CI:** Chromium e2e, strict Clippy on Linux, `pnpm build`, Pandoc on every OS,
  `e2e-testing` Rust tests, and fail-on-flaky Playwright.

## Follow-Ups

- A plugin stuck in native code is abandoned after the timeout but its thread keeps
  one CPU core busy until the app quits.
- Book Translation has no e2e test that drives `file-sync` through the real plugin;
  it is covered by the plugin-document-session unit tests.
